Quick Guide

How It Works

Resize hundreds of photos in three effortless, automated steps.

1

Select Format / Upload File

Drag and drop individual image files or select an entire directory. The tool automatically analyzes each image and categorizes it into Horizontal, Vertical, or Square based on its true aspect ratio.

2

Configure & Customize

Toggle preset target widths or add custom pixel sizes for each orientation. Pick your output format (Original, JPG, PNG, or WebP), customize compression fidelity, and set naming prefixes or suffixes.

3

Instant Download & Use

Click Resize Images to process everything client-side in seconds. Download files one by one or click "Download All (ZIP)" to receive every generated size organized with your folder structure intact.

Got Questions?

Frequently Asked Questions

Everything you need to know about batch resizing images in your browser.

Why does Bulk Image Resizer sort images by orientation?

Traditional batch resizers force a uniform width or height across every file, which breaks portrait photos or requires you to manually separate landscape and portrait shots beforehand. Bulk Image Resizer automatically identifies whether each photo is Horizontal, Vertical, or Square, and applies tailored target widths to each orientation in a single automatic pass while preserving original aspect ratios.

Are my photos uploaded to any server or cloud storage?

No, never. This tool runs 100% locally within your web browser using HTML5 Canvas and Web APIs. Your images, filenames, and folder structures are processed directly on your computer's CPU/GPU and are never sent over the internet or stored on our servers.

Will smaller images be stretched or enlarged?

No. The engine includes strict No-Upscaling Protection. If a target width is greater than or equal to the image's original width, that specific size is safely bypassed so your images are never artificially stretched, blurred, or interpolated.

How do I download all resized images at once?

Once batch resizing completes, click the Download All (ZIP) button. The browser will package all generated sizes into a single clean ZIP archive. If you uploaded a folder with subdirectories, you can enable "Preserve Folder Hierarchy" to keep your directory tree intact inside the archive.
